# Airbnb MCP Agent 🏡🤖

An **AI-powered Airbnb assistant built using the Model Context Protocol
(MCP)** that can search, analyze, and reason over Airbnb-style listings
using structured tools and LLM-based agents.

This project demonstrates how to build a **tool-using MCP agent** that
interacts with external data sources, performs reasoning, and returns
structured, actionable results.

------------------------------------------------------------------------

## 🚀 Features

-   🔌 MCP-based Agent Architecture\
-   🧠 LLM-driven reasoning and decision making\
-   🏘️ Airbnb-style listing search and filtering\
-   📊 Price, location, and amenity analysis\
-   🛠️ Tool calling via MCP server\
-   📓 Jupyter Notebook--based experimentation

## 🧠 What is MCP?

**Model Context Protocol (MCP)** is a standardized way for LLMs to: -
Discover tools\
- Call tools with structured inputs\
- Receive structured outputs\
- Maintain clean separation between reasoning and execution
